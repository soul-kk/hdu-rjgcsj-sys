# 学生驿站 — 前端（React + Vite）

校园快递驿站数字化管理系统前端，基于 React 18 + Vite + Ant Design 5。

## 启动方式

```bash
# 先启动后端（server/ 目录）
cd ../server && npm run dev

# 再启动前端
npm run dev
```

前端访问：http://localhost:5173  
后端 API：http://localhost:3001
